Course use cases loaded at runtime by the "Use Cases" tab.

* `index.json` lists the files to load: `{ "version": 1, "usecases": [ { "id": "...", "file": "....json" } ] }`
* each `<id>.json` holds the texts, the editable parameters and the model (same format as a project saved by the modeler).

Generated by `npm run usecases:build` (scripts/build-usecases.ts); hand-written files are welcome too.
